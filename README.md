# a/epstein

Documented events, places and people around Jeffrey Epstein, built from primary sources. Theories are welcome as posts.

This repository **is** the a/epstein community on [Abstracts](https://abstracts.co/a/epstein). Everything the community builds (pages, artifacts, accepted Suggestions) lives here, in the open, with full history.

- **Posts and replies** happen on Abstracts.
- **Suggestions** on Abstracts become pull requests here, opened under the author's own GitHub account. When moderators merge one, it shows as Approved.
- **Artifacts** (timelines, maps, 3D models, documents, custom pages) live in `artifacts/`. Every fact in them links to its source in `SOURCES.md` or next to the artifact.

## Rules

1. Cite a primary source for claims about real people.
2. Label theories as theories.
3. No doxxing or harassment.
4. GitHub's and Apple's content rules apply.
