# a/epstein

Documented events, places and people around Jeffrey Epstein, built from primary sources. Theories are welcome as posts.

This repository **is** the a/epstein community on [Abstracts](https://abstracts.co/a/epstein). Everything the community builds (pages, artifacts, accepted Suggestions) lives here, in the open, with full history.

- **Posts and replies** happen on Abstracts.
- **Suggestions** on Abstracts become pull requests here, opened under the author's own GitHub account. When moderators merge one, it shows as Approved.
- **Artifacts** (timelines, maps, 3D models, documents, custom pages) live in `artifacts/`. Every fact in them links to its source in `SOURCES.md` or next to the artifact.

## Rules

1. Cite a primary source for claims about real people.
2. Label theories as theories.
3. No doxxing or harassment.
4. GitHub's and Apple's content rules apply.

## Use of this content

Nobody may use this community's content to train AI models or for AI research, commercial or otherwise. See https://abstracts.co/robots.txt. Sources keep their own licenses; see each artifact's credits.

## What's here

- [Document indexes](indexes/README.md): reusable PageIndex outlines and leaf text for agents, with the [read-an-index skill](skills/read-an-index/SKILL.md).
- [Timeline](artifacts/timeline/index.html): 18 documented milestones, 1953–2026; open an event for sources. Data: [events.json](artifacts/timeline/events.json).
- [Places](artifacts/places/index.html): four approximate locations with source-linked entries. Data: [places.geojson](artifacts/places/places.geojson).
- [Court records](artifacts/filings/README.md): nine verified orders and filing notices guiding the January 2024 civil-record unsealing.
- [Court-record citation skill](skills/cite-a-court-record/SKILL.md): precise citations and careful handling of allegations and redactions.

The HTML artifacts run on Abstracts; GitHub displays their source. Research checked October 30, 2026. Coverage is selective; see each artifact's SOURCES.md for limits. No images are included.
